# 醒来 WAKIE — AI 闹钟交互原型

一个围绕“带着目的醒来”设计的 AI 闹钟 Demo。用户可以通过语音或文字描述时间、要做的事和背后的理由，由界面整理成可确认的提醒，并在日程中统一查看。

## 功能亮点

- 语音指令交互：点击语音按钮开始或结束录入
- 文字指令输入：用自然语言描述提醒内容
- AI 整理确认：将时间、事项和动机展示为结构化确认卡片
- 日程视图：按日期浏览提醒和当天任务
- 待定想法：展示尚未安排日期的话题与计划
- 移动端原型：以手机界面呈现完整交互流程

## 当前演示范围

本仓库目前是前端交互原型。语音识别、AI 解析、提醒通知和数据持久化均使用演示交互或静态数据，尚未接入实际服务。

## 技术栈

- React 19
- Next.js 16
- TypeScript
- vinext / Vite
- Tailwind CSS 4
- Cloudflare Workers（运行环境）
- Drizzle ORM / Cloudflare D1（预留数据层）

## 环境要求

- Node.js `>= 22.13.0`
- npm


## 交互体验

1. 在“创建”页面点击语音圆球，模拟开始录音。
2. 再次点击结束录音，查看 AI 整理后的确认卡片。
3. 也可以点击文字入口输入自然语言指令。
4. 切换到底部“日程”标签，按日期查看任务与待定想法。
